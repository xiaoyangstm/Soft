# 实验室环境监测与智能控制系统 —— 项目完整实现文档

---

## 一、项目概述

本项目是一个**物联网实验室环境监测与控制系统**，由三个部分组成：

| 层级 | 角色 | 说明 |
|------|------|------|
| 下位机 | 传感器/设备端 | 采集温度、湿度、光照、火焰、烟雾数据，通过 MQTT 上报 |
| 上位机 | Android App | 接收传感器数据并展示，设置阈值，远程控制设备，转发数据到云平台 |
| 云平台 | OneNet | 存储历史数据，提供可视化界面远程查看 |

**整体数据流向：**

```
下位机(传感器)
    │
    │ MQTT发布 → 主题: sl_pst
    ▼
EMQX消息服务器(Broker)
    │
    │ MQTT订阅 ← 主题: sl_pst
    ▼
Android上位机(App)
    ├── 显示数据到界面
    ├── 判断阈值并报警
    ├── 发送控制命令 → 主题: sl_sub → 下位机执行
    │
    │ MQTT发布 → 主题: $sys/0hI8il1EnF/peng/thing/property/post
    ▼
OneNet云平台
    └── 数据存储与可视化
```

## 三、EMQX消息服务器的搭建

### 3.1 什么是MQTT

MQTT（Message Queuing Telemetry Transport）是一种轻量级的发布/订阅模式的消息协议，专为物联网设计。它的核心概念：

- **Broker（消息服务器）**：所有消息的中转站，类似邮局
- **发布者（Publisher）**：发送消息的设备，类似寄信人
- **订阅者（Subscriber）**：接收消息的设备，类似收信人
- **主题（Topic）**：消息的分类标签，类似信箱编号

**工作流程：**
1. 发布者把消息发给Broker，标明主题
2. Broker把消息转发给所有订阅了该主题的订阅者
3. 订阅者只需要关心自己订阅的主题

```
发布者(下位机) ──发布消息到主题sl_pst──▶ Broker(EMQX) ──转发给订阅者──▶ 订阅者(App)
```

### 3.2 什么是EMQX

EMQX 是一个开源的 MQTT 消息服务器（Broker），负责接收所有设备的消息并转发。本项目使用的地址是 `10.1.1.89`，端口 `1883`。

### 3.3 EMQX安装步骤（Linux服务器）

```bash
# 1. 下载EMQX（以Ubuntu为例）
wget https://www.emqx.com/zh/downloads/broker/5.0.26/emqx-5.0.26-ubuntu20.04-amd64.deb

# 2. 安装
sudo dpkg -i emqx-5.0.26-ubuntu20.04-amd64.deb

# 3. 启动EMQX
sudo systemctl start emqx

# 4. 设置开机自启
sudo systemctl enable emqx

# 5. 查看状态
sudo systemctl status emqx
```

### 3.4 EMQX管理后台

安装完成后，打开浏览器访问：

```
http://你的服务器IP:18083
```

- 默认用户名：`admin`
- 默认密码：`public`

在管理后台可以：
- 查看已连接的设备
- 查看主题订阅情况
- 监控消息流量
- 管理客户端认证

### 3.5 本项目的MQTT主题设计

| 主题 | 方向 | 用途 |
|------|------|------|
| `sl_pst` | 下位机 → App | 传感器数据上报（温度、湿度、光照、火焰、烟雾） |
| `sl_sub` | App → 下位机 | 控制命令下发（灯光、通风、空调、窗帘、加湿器、阈值设置） |

## 四、OneNet云平台配置

### 4.1 什么是OneNet

OneNet 是中国移动提供的物联网云平台，可以存储设备上报的数据，并提供网页端的数据可视化界面。本项目使用的是**旧版OneNet**。

### 4.2 OneNet配置步骤

#### 第一步：注册账号并创建产品

1. 访问 [OneNet官网](https://open.iot.10086.cn/)，注册账号
2. 进入控制台，点击「全部产品」→「多协议接入」
3. 点击「添加产品」，填写信息：
   - 产品名称：`peng`
   - 产品ID：`0hI8il1EnF`（系统自动生成）
   - 协议：选择 `MQTT`
   - 联网方式：选择 `WiFi`

#### 第二步：创建设备

1. 进入产品 `peng` 的设备管理页面
2. 点击「添加设备」
   - 设备名称：`peng`
   - 设备密钥：`RFc4TU1UN2xSVWhQSU1RMHltc1RQWnpMSEtYNzU2R3Q=`

#### 第三步：定义物模型（数据流模板）

在产品设置中，添加5个数据流模板，对应5个传感器数据：

| 标识符 | 名称 | 数据类型 | 说明 |
|--------|------|----------|------|
| `t` | 温度 | int | 温度值，单位℃ |
| `h` | 湿度 | int | 湿度值，单位% |
| `l` | 光照 | int | 光照值，单位% |
| `f` | 火焰 | int | 火焰值，单位% |
| `s` | 烟雾 | int | 烟雾值，单位% |

#### 第四步：生成Token

OneNet的MQTT连接需要Token认证，使用OneNet提供的Token生成工具：

- **method**：`md5`
- **res**：`products/0hI8il1EnF/devices/peng`（URL编码后为 `products%2F0hI8il1EnF%2Fdevices%2Fpeng`）
- **et**：`3104890835`（过期时间戳，设置足够大）
- **key**：设备密钥 `RFc4TU1UN2xSVWhQSU1RMHltc1RQWnpMSEtYNzU2R3Q=`

生成的Token为：
```
version=2018-10-31&res=products%2F0hI8il1EnF%2Fdevices%2Fpeng&et=3104890835&method=md5&sign=muS32SDwZVyHwWBTJfPJqA%3D%3D
```

#### 第五步：OneNet MQTT连接参数

| 参数 | 值 | 说明 |
|------|-----|------|
| Broker地址 | `183.230.40.96` | OneNet的MQTT服务器IP |
| 端口 | `1883` | MQTT默认端口 |
| ClientId | `peng` | 设备名称 |
| UserName | `0hI8il1EnF` | 产品ID |
| Password | Token字符串 | 第四步生成的Token |

#### 第六步：OneNet数据上报主题

```
$sys/0hI8il1EnF/peng/thing/property/post
```

上报的数据格式（OneJSON）：
```json
{
    "id": "123",
    "version": "1.0",
    "params": {
        "t": { "value": 30 },
        "h": { "value": 65 },
        "l": { "value": 65 },
        "f": { "value": 20 },
        "s": { "value": 12 }

```

其中 `t`、`h`、`l`、`f`、`s` 是在第三步中定义的标识符，必须完全一致。

### 5.4 核心库说明

#### SimpleActivity

所有页面的父类，提供了：
- `startActivity(XXXActivity.class)`：跳转到其他页面
- `iapp.tw("消息")`：弹出Toast提示
- 统一的生命周期管理

#### MqttTools

MQTT通信工具类，封装了连接、订阅、发布等操作：

| 方法 | 作用 | 示例 |
|------|------|------|
| `setHostUrl(url)` | 设置MQTT服务器地址 | `"tcp://10.1.1.89:1883"` |
| `setUserName(name)` | 设置用户名 | `"peng"` |
| `setPassword(pwd)` | 设置密码 | Token字符串 |
| `setClientId(id)` | 设置客户端ID | `"peng"` |
| `connect(listener)` | 连接服务器 | 连接成功/失败回调 |
| `subscribe(topic, qos)` | 订阅主题 | `subscribe("sl_pst", 0)` |
| `publish(topic, msg)` | 发布消息 | `publish("sl_sub", json)` |

**重要特性**：`simple_emqx` 库要求**必须先订阅一个主题，才能向该主题发布消息**。否则会报错 `the topic 'xxx' not subscribed!`。

#### IMqttCallBack

MQTT消息回调接口：

| 方法 | 触发时机 |
|------|----------|
| `onMessage(topic, message)` | 收到订阅主题的消息时 |
| `onConnectionLost()` | MQTT连接断开时 |

```java
public class Activityshow extends SimpleActivity implements IMqttCallBack {
    private ActivityShowBinding binding;
    MqttTools mqttTools;        // EMQX连接（接收下位机数据）
    MqttTools onenetMqttTools;  // OneNet连接（转发数据到云平台）
    private boolean onenetConnected = false;  // OneNet连接状态标志

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        binding = ActivityShowBinding.inflate(getLayoutInflater());
        setContentView(binding.getRoot());

        // ========== 第一部分：连接EMQX服务器 ==========
        mqttTools = new MqttTools();
        mqttTools.setHostUrl("tcp://10.1.1.89:1883");  // EMQX服务器地址
        mqttTools.connect(new IMqttActionListener() {
            @Override
            public void onSuccess(IMqttToken iMqttToken) {
                // 连接成功后，订阅传感器数据主题
                mqttTools.subscribe("sl_pst", 0);
            }
            @Override
            public void onFailure(IMqttToken iMqttToken, Throwable throwable) {
                // 连接失败处理
            }
        });

        // ========== 第二部分：连接OneNet云平台 ==========
        onenetMqttTools = new MqttTools();
        onenetMqttTools.setHostUrl("tcp://183.230.40.96:1883");  // OneNet服务器地址
        onenetMqttTools.setUserName("0hI8il1EnF");                // 产品ID
        onenetMqttTools.setPassword("version=2018-10-31&...");    // Token
        onenetMqttTools.setClientId("peng");                      // 设备名称
        onenetMqttTools.connect(new IMqttActionListener() {
            @Override
            public void onSuccess(IMqttToken iMqttToken) {
                onenetConnected = true;
                // 必须先订阅才能发布（simple_emqx库的要求）
                onenetMqttTools.subscribe("$sys/0hI8il1EnF/peng/thing/property/post", 0);
            }
            @Override
            public void onFailure(IMqttToken iMqttToken, Throwable throwable) {
                onenetConnected = false;
            }
        });

        // ========== 第三部分：返回按钮 ==========
        binding.back.setOnClickListener(v -> {
            startActivity(TeamActivity.class);
            finish();
        });

        // ========== 第四部分：网络时间更新 ==========
        startNetworkTimeUpdates();
```

**接收消息并转发到OneNet的核心逻辑**：

```java
    @Override
    public void onMessage(String s, MqttMessage mqttMessage) throws Exception {
        // 只处理 sl_pst 主题的消息
        if (s.equals("sl_pst") && mqttMessage.isJSONObject()) {
            JSONObject data = mqttMessage.getJSONObject();
            runOnUiThread(() -> {
                try {
                    String tempValue = null, humiValue = null, lightValue = null,
                           fireValue = null, smokeValue = null;

                    // 解析并显示温度
                    if (data.has("temperature")) {
                        tempValue = data.getString("temperature");
                        binding.temperatureText.setText(tempValue + "℃");
                    }
                    // 解析并显示湿度
                    if (data.has("humidity")) {
                        humiValue = data.getString("humidity");
                        binding.humidityText.setText(humiValue + "%");
                    }
                    // 解析并显示光照
                    if (data.has("light")) {
                        lightValue = data.getString("light");
                        binding.lightText.setText(lightValue + "%");
                    }
                    // 解析并显示火焰
                    if (data.has("fire")) {
                        fireValue = data.getString("fire");
                        binding.fireText.setText(fireValue + "%");
                    }
                    // 解析并显示烟雾
                    if (data.has("smoke")) {
                        smokeValue = data.getString("smoke");
                        binding.smokeText.setText(smokeValue + "%");
                    }

                    // 将数据转发到OneNet云平台
                    publishToOneNet(tempValue, humiValue, lightValue, fireValue, smokeValue);

                } catch (JSONException e) {
                    Log.e("UI", "数据解析失败", e);
                }
            });
        }
    }
```

**转发到OneNet的方法**：

```java
    private void publishToOneNet(String temp, String humi, String light,
                                  String fire, String smoke) {
        // 检查OneNet是否已连接
        if (!onenetConnected) {
            Log.w("OneNet", "OneNet未连接，跳过上报");
            return;
        }
        try {
            // 构建OneJSON格式数据
            JSONObject payload = new JSONObject();
            payload.put("id", "123");
            payload.put("version", "1.0");

            JSONObject params = new JSONObject();

            if (temp != null) {
                JSONObject t = new JSONObject();
                t.put("value", Integer.parseInt(temp));
                params.put("t", t);       // t = 温度标识符
            }
            if (humi != null) {
                JSONObject h = new JSONObject();
                h.put("value", Integer.parseInt(humi));
                params.put("h", h);       // h = 湿度标识符
            }
            if (light != null) {
                JSONObject l = new JSONObject();
                l.put("value", Integer.parseInt(light));
                params.put("l", l);       // l = 光照标识符
            }
            if (fire != null) {
                JSONObject f = new JSONObject();
                f.put("value", Integer.parseInt(fire));
                params.put("f", f);       // f = 火焰标识符
            }
            if (smoke != null) {
                JSONObject s = new JSONObject();
                s.put("value", Integer.parseInt(smoke));
                params.put("s", s);       // s = 烟雾标识符
            }

            payload.put("params", params);

            // 发布到OneNet
            String topic = "$sys/0hI8il1EnF/peng/thing/property/post";
            onenetMqttTools.publish(topic, payload.toString());

        } catch (Exception e) {
            Log.e("OneNet", "上报OneNet失败", e);
        }
    }
```

## 七、MQTT双连接架构

本项目中，`Activityshow` 同时维护了两个独立的MQTT连接：

```
┌─────────────────────────────────────────────────────┐
│                   Activityshow                       │
│                                                     │
│  ┌─────────────────┐     ┌─────────────────────┐   │
│  │   mqttTools     │     │  onenetMqttTools    │   │
│  │  (EMQX连接)     │     │  (OneNet连接)       │   │
│  │                 │     │                     │   │
│  │ 订阅: sl_pst    │     │ 订阅: $sys/.../post │   │
│  │ 接收传感器数据   │     │ 发布: $sys/.../post │   │
│  └────────┬────────┘     └──────────┬──────────┘   │
│           │                         │               │
└───────────┼─────────────────────────┼───────────────┘
            │                         │
            ▼                         ▼
    ┌──────────────┐         ┌──────────────┐
    │  EMQX Broker │         │  OneNet平台   │
    │  10.1.1.89   │         │ 183.230.40.96│
    └──────────────┘         └──────────────┘
```

**两个连接完全独立**，互不影响：
- `mqttTools`：负责与本地EMQX通信，接收下位机数据
- `onenetMqttTools`：负责与OneNet云平台通信，转发数据

## 八、关键问题与解决方案

### 8.1 simple_emqx库必须先订阅才能发布

**问题**：直接调用 `publish()` 发布消息，日志报错 `the topic 'xxx' not subscribed!`，消息发送失败。

**原因**：`simple_emqx` 库的设计要求必须先 `subscribe` 一个主题，才能向该主题 `publish` 消息。

**解决**：在连接成功回调中，先订阅需要发布的主题：
```java
@Override
public void onSuccess(IMqttToken iMqttToken) {
    // 先订阅，才能发布
    onenetMqttTools.subscribe("$sys/0hI8il1EnF/peng/thing/property/post", 0);
}
```

### 8.2 OneNet连接时序问题

**问题**：下位机数据可能在OneNet连接成功之前就到了，此时发布会失败。

**解决**：使用 `onenetConnected` 标志位，只有连接成功后才转发数据：
```java
private void publishToOneNet(...) {
    if (!onenetConnected) {
        return;  // 未连接则跳过
    }
    // ... 发布逻辑
}
```

### 8.3 数据类型问题

**问题**：传感器数据全部是整型，如果使用 `Double.parseDouble` 会产生小数点，与OneNet物模型定义的int类型不匹配。

**解决**：统一使用 `Integer.parseInt`，确保数据类型与OneNet物模型一致。

## 十一、总结

本项目的核心思路是：

1. **下位机采集数据** → 通过MQTT发布到EMQX
2. **App订阅接收数据** → 显示到界面 + 转发到OneNet云平台
3. **App发送控制命令** → 通过MQTT发布到EMQX → 下位机执行
4. **OneNet存储数据** → 提供远程可视化查看

整个系统通过MQTT协议将下位机、上位机、云平台三层串联起来，实现了数据的采集、展示、存储和远程控制。
